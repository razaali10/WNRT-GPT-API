# Privacy Policy – WNTR Analysis Assistant

**Effective Date:** [Insert Today’s Date]

The WNTR Analysis Assistant GPT and its connected API do not collect or store any personally identifiable information (PII) from users.

## What We Collect

When you use this assistant:
- You may provide EPANET `.inp` file content for hydraulic simulation.
- This data is processed temporarily by the backend API for analysis purposes only.

We do **not**:
- Store `.inp` file content
- Log conversations
- Associate inputs with identity or location

## How Your Data is Used

Data is processed in memory solely to:
- Simulate network hydraulics or quality
- Perform resilience, economic loss, or criticality analysis
- Generate summaries using GPT-4

Results are returned directly and not stored or shared.
